# roster.csv

One row per person. `username` is the institution's identifier and forms the
repository name; `github_id` is the GitHub login (blank until the student
supplies it; `students import` fills it from a form export). `role` is
student, test, teacher or staff. Keep ONE row with role=test for a GitHub
account you control: every assignment goes to it before students see it.

This file holds names and email addresses. Keep the course folder private.
