# a01: Hello, graded in JavaScript

Web Programming

## What to do

1. Open `app.js` and complete the functions marked `TODO`.
2. Run the tests as often as you like:

       npm test

   Every check prints `PASS` or `FAIL`, and every failure comes with a hint.
   Nothing needs to be installed: the tests use only what ships with Node.

3. Commit and push to GitHub. Each push runs the same tests and puts a green
   tick or a red X on your commit.

## What the tick means

The tick is a convenience, not your grade. It says "what you pushed passes the
visible tests". Your instructor grades from a fresh copy of your repository
using the instructor's own copy of the tests, so editing `test.js` changes
what you see locally and nothing else.
